# scratch-paint 互換性調査

対象: `.tmp/scratch-editor/packages/scratch-paint` と `packages/editor` のコスチューム編集機能。参照側は AGPL-3.0-only、現行パッケージは MIT と申告されているため、実装の直接コピーや移植にはライセンス確認が必要。以下は比較開始時の観測とサブエージェントによる調査結果であり、全件を動作試験で確認した一覧ではない。作業中の修正によって行番号や状況は変わりうる。

## 基盤・履歴・入出力

- Scratch は Paper.js のプロジェクト、ラスタ、描画・ガイドレイヤーを中心に編集する。現行はビットマップを Canvas、ベクターを SVG と必要時の Paper.js インポートで扱う。選択対象・ヒットテスト・変形や保存単位が異なる。
- Scratch の履歴は Paper の JSON スナップショットで最大100件。現行はアセットのバイト列とメタデータを使い、描画履歴を音声から分離してコスチューム切替時にクリアするよう修正した。最大100件・容量制限付きで、単一の大容量スナップショットは直前のUndoを保つため例外的に保持する。保存形式は異なる。
- Scratch は SVG 取込時のサニタイズ、スケールと回転中心の調整、書出時の境界算出を行う。現行は独自の SVG 処理と Canvas 変換を使う。ビットマップ→ベクターでは埋込み画像を使い、参照側もトレースではなくラスタを挿入するため、その点自体は差分ではない。

## ベクター描画

- ブラシ: Scratch はサイズとズームに応じたストローク生成、同色図形との結合、カーソルプレビューを備える。現行にも塗りの閉形状と条件付きの同色結合を接続し、実画面で作画・結合・Undo／Redo を確認した。太さの独立設定、平滑化、複雑な重なりと Z 順の完全一致は未検証。
- 長方形・楕円: Scratch は Shift で正方形・正円、Alt で中心基準、微小図形の破棄と作成後の選択を行う。比較開始時にはドラッグ修飾がなかったため、ビットマップ・ベクター双方の矩形／楕円に追加した。比較開始時の現行矩形は角丸 `rx=8` だったため、通常の矩形に変更した。現行はクリック時に定型サイズの形状を置く動作もある。
- 直線: Scratch は専用ツールを使い、現行は SVG パスを生成する。線幅や描画時の扱いが異なる。
- 塗り: Scratch はホバー時のプレビュー、輪郭・塗りの判定、複合パスの穴、グラデーションの位置を扱う。現行にも対象範囲とクリック位置に基づくグラデーションを追加し、複数形状で実画素を検証した。塗り・輪郭をヒット面ごとに変更し、対応可能な複合パスの穴は独立形として塗るようにした。曖昧な穴は安全のため変更しない。非永続ホバープレビューも追加し、表示と離脱・履歴非変更を実画面で検証した。
- テキスト: Scratch はキャンバス上のテキスト編集とフォント選択を提供する。比較開始時は入力欄から静的 SVG を作るのみだったが、キャンバス上の作成・既存テキストの再編集・フォントとサイズの選択を追加した。IME変換中の Escape／Enter が編集全体を確定しないよう修正し、合成 composition イベントで両モードを検証した。RTL の新規作成・保存・再編集と複数行を両モードで実画面検証した。OS の日本語IME実機、Scratch 固有フォントや変形の細部は未検証または未対応。参照が使う [scratch-render-fonts の npm メタデータ](https://registry.npmjs.org/scratch-render-fonts/1.0.258)にはライセンス欄がなく、個別フォントの再配布条件は未確認のため同梱していない。

## ビットマップ描画

- ブラシ: Scratch は整数のピクセル座標を Bresenham で補間し、サイズ5以下は四角、それ以上は楕円のスタンプを配置する。比較開始時は平滑化された Canvas ストロークだったが、ピクセルスタンプに変更した。直径1〜100で参照との画素一致と同径の消し残しゼロを実 Canvas で検証した。ブラシと消しゴムは同じスタンプ形状を使う。
- 直線: Scratch はブラシマークを整数座標上に並べる。比較開始時は Canvas の `lineTo` と stroke で描いていたが、ブラシと共通のピクセルスタンプ方式に変更した。共通スタンプの直径1〜100の境界画素は参照と一致することを確認した。
- 矩形・楕円: Scratch は塗り／輪郭を切り替え、Shift・Alt 修飾、変形中の選択、ラスターへの確定をサポートする。現行は Canvas に直接描画し、塗りと輪郭を排他的に切り替えられるようにした。輪郭で参照する色と太さを塗り色・ブラシサイズに修正し、実画面で確認した。回転を含む中間図形の変形には差が残る。
- 塗りつぶし: Scratch は RGBA の完全一致で連結領域を塗り、Shift で同色の全画素を置換する。透明色とグラデーション用マスクにも対応する。比較開始時の現行実装は色距離に許容差を持つ連結塗りだったため、厳密一致と Shift 全置換を接続した。グラデーション塗りもマスク合成で追加した。透明色と透明ストップも追加した。放射グラデーションの中心をクリック点に合わせ、Shift 全置換・透明端・履歴を実画面で検証した。その他の境界条件は未検証。
- テキスト: Scratch は共通のテキストツールで編集後にラスタ化する。比較開始時は固定フォントで即座に Canvas に描いていたが、インライン編集とフォント・サイズ選択を追加した。ラスタ化後の再編集・選択の振る舞いは未検証。
- スポイト: Scratch は専用ツールと拡大鏡、透明色をサポートする。現行にもビットマップ／ベクターの専用スポイト、ルーペ、塗り／枠線と透明色の取得を追加した。ルーペの倍率・半径やタッチ実機での一致は未検証。

## 選択・変形

- Scratch の選択はガイドを除外し、ズーム連動許容差、ハンドル優先判定、ホバー表示を使う。現行は SVG 子要素のインデックスと Paper のヒットテストを中心に管理する。
- Scratch のマーキー選択はパスとの交差、グループ、リシェイプ中の点選択を扱う。現行にもオブジェクト単位とリシェイプ中の点単位の矩形選択を追加した。グループ内選択などは引き続き差がある。
- Scratch はグループ内の部分選択、選択ルートと葉の区別を持つ。現行は主としてトップレベル SVG 要素を選択する。グループ内の矩形などの点をリシェイプで操作できるようにし、全要素をグループ化すると選択枠が消える問題も修正した。点移動・Undo／Redo・グループ解除を実画面で検証した。リシェイプ中に対応可能な図形の子要素を独立選択・移動できるようにした。文字・画像・クリップ・複合パスなどは安全のため対象外。
- 移動: Scratch は Shift 角度スナップ、特定操作での中心スナップ、Alt 複製、ズーム連動の矢印キー移動を持つ。現行に Shift スナップ、Alt 複製、ズーム連動の矢印移動とキーアップ時の履歴まとめを追加した。中心スナップや移動範囲の扱いには差が残る。
- スケール: Scratch は Alt 中心、角ハンドルは通常等比・Shift で自由比、複数選択の一括スケールを扱う。現行の単一図形と複数選択の共有バウンズに Alt／Shift による拡縮を追加した。ハンドルが画面端で隠れる場合や枠線幅の拡縮などには差が残る。
- 回転: Scratch はドラッグハンドルと Shift 角度スナップを持つ。現行にもビットマップ／ベクターの回転ハンドルと Shift スナップを追加し、実画面で確認した。戻した場合の空履歴と Escape 直後の編集競合も修正し、角度・半透明・履歴の実画面テストを実行した。キーボード操作は未対応。
- リシェイプ: Scratch は点の追加・削除、複数点選択、点マーキー、曲線ハンドル編集を提供する。現行は点・ハンドルドラッグ、曲線クリックでの点追加・削除、選択アンカーの曲線化／直線化を実装した。Shift による複数点選択、点マーキー、一括移動・曲線化／直線化・削除も追加した。点ドラッグ中の Escape 復元・履歴保護も追加した。複数制御点の独立一括移動は未対応。
- ビットマップ選択: Scratch は不透明領域へ選択範囲を詰め、選択したラスタを浮動させて移動・拡縮・回転後に確定する。現行にも不透明範囲への切り詰め、浮動選択の移動・複製、8ハンドルの拡縮、90°回転を追加した。Shift／Alt・反転と任意角回転も実画面で検証した。半透明画素や一部境界条件はさらに検証が必要。
- コピー／貼付: Scratch は Paper アイテムと貼付オフセットを扱う。現行もビットマップを `ImageData` として保持し、両モード間の貼付・オフセット・Undo／Redoを追加した。座標換算や SVG 参照の全条件は引き続き検証が必要。

## UI・操作

- Scratch の色選択は HSV、2色、入替、透過、スポイト、4種類の塗りを備える。現行にはHSVスライダーとネイティブ色入力、グラデーション選択、不透明度入力と透明切替がある。混在・透明状態からのHSV変更は選択図形へ即時反映し、連続変更は履歴をまとめる。塗りの2色交換を追加した。独立した輪郭グラデーションの作成・色交換・選択図形への適用を追加し、実画面で確認した。選択色の MIXED 表示と項目単位の適用を追加し、解釈できないSVG色は保持する。選択変更時に未適用色が別オブジェクトへ漏れる回帰も修正した。スポイトの外観・タッチ挙動には差が残る。
- Scratch のツール別 UI には独立したブラシ・消しゴムサイズ、塗り／輪郭、フォント、曲線／直線ポイントなどがある。現行には未接続または未実装の操作がある。
- Scratch のキーボード操作には Esc、削除、Undo/Redo、グループ化、コピー／カット／貼付、全選択、矢印キー移動がある。比較開始時は一部のみだったため、選択解除・全選択・コピー／カット／貼付・グループ化・矢印キーの操作を追加した。モード横断の貼付は追加した。点単位の矢印移動などには差が残る。
- ズームとパンは Scratch の Paper ビューと現行の CSS 変換で異なる。Ctrl／Meta ホイールのカーソル固定、Shift ホイールの横パン、行単位補正を追加し、ズーム連動の選択・点追加許容差も調整した。倍率増分、ハンドル・描画太さなどは要確認。
- Scratch は翻訳と RTL を考慮している。現行は日本語・英語の固定文字列が混在する。

## 参照フォント資産の由来

Scratch が参照する [scratch-render-fonts](https://github.com/scratchfoundation/scratch-render-fonts) は、Sans Serif、Serif、Handwriting、Marker、Curly、Pixel 等に対応するフォントを配布している。[公開版 1.0.259 のメタデータ](https://registry.npmjs.org/scratch-render-fonts/1.0.259)にはライセンス欄がなく、リポジトリの [Apache-2.0 ライセンス](https://github.com/scratchfoundation/scratch-render-fonts/blob/master/LICENSE.txt)と [OFL 文書](https://github.com/scratchfoundation/scratch-render-fonts/blob/master/OFL.txt)のどちらが各バイナリに適用されるかは、その記載だけでは確認できなかった。OFL 文書は Londrina に言及する一方、現在の同梱一覧には同名ファイルがない。

Handlee、Knewave、Griffy、Source Serif の各上流には OFL 文書があるが、Scratch 配布バイナリとの一致や適用条件は未照合。Pixel 用 Grand9K Pixel と Scratch.ttf の個別の再配布許諾も未確認。そのため、参照フォント名は選択できるようにしたが、バイナリは同梱していない。配布前には各バイナリの由来・適用ライセンス・著作権表示と、必要に応じた Reserved Font Name の条件について人の確認が必要。

## ライセンス由来の要確認箇所

静的比較では、[bitmap-stamp.ts](../packages/editor/src/features/costumes/bitmap-stamp.ts)（旧ビットマップ消しゴムの楕円処理）、[bitmap-eraser.ts](../packages/editor/src/features/costumes/bitmap-eraser.ts)、[bitmap-fill.ts](../packages/editor/src/features/costumes/bitmap-fill.ts)、[vector-eraser.ts](../packages/editor/src/features/costumes/vector-eraser.ts) に参照元からの移植を明記するコメントがあり、一部は変数名や制御構造まで参照コードに近い。特にビットマップ消しゴムの楕円描画とベクター消しゴムのパス分割、走査線塗りつぶしは個別に人のレビューが必要。[THIRD-PARTY.md](../packages/editor/THIRD-PARTY.md) には調査時点で scratch-paint の記載がない。AGPL と MIT の配布条件についてここで法的結論は出さないが、配布前に由来と条件を確認すること。

## 今回の修正と検証状況

- ベクターとビットマップの矩形／楕円ドラッグに Shift・Alt 修飾を追加し、ベクター矩形の角丸を除去。ベクター直線は逆方向のドラッグも始点と終点を保持する。単一選択の拡縮は通常等比・Shift 自由比・Alt 中心基準に対応した。
- ビットマップブラシをピクセルスタンプ方式に変更し、参照と同じ輪郭を消しゴムと共用。実 Canvas の直径1〜100の検証で参照との差と同径消し残しはいずれも0だった。共用実装の由来にはライセンス確認が必要。
- ビットマップの塗りを RGBA 厳密一致に変更し、Shift による全置換、透明色とグラデーション用マスクを追加。実画面で透明塗り・Undo／Redo と透明ブラシの消去を確認した。放射状のクリック中心は実画面で確認した。
- ベクター消しゴムの複合パスや基本図形の処理を修正。実 Paper.js と DOM を使うテストで、中央消去後の周辺と別図形の保持を確認。
- 選択・コピー／カット／貼付・グループなどのショートカットとツールバーの一部を接続。複数選択は共通中心での反転・回転と共有境界での拡縮に対応した。モード横断貼付も実装し、異なる解像度・回転中心での実画面検証を追加した。
- ビットマップとベクターのインライン文字入力を追加し、Enter 改行・Escape 確定に変更。実エディターで複数行の作成と Undo/Redo を確認した。複数行の再編集で改行が消える不具合も修正し、実エディターで再編集を確認した。
- 頂点の追加・削除をエディターのリシェイプ操作に接続し、実画面で追加・削除・Undo／Redo を確認した。変換付きグループの子図形と、条件を満たす文字・画像の移動は実 UI でも検証した。複合パスやクリップ等は未対応の条件が残る。
- 複数穴を持つ直線や一部の曲線の複合パス、相対 `m` の穴と、安全条件を満たす入れ子輪郭の最内穴を個別に塗れるようにし、実画面で画素・履歴・重なり順を検証した。島を含む外側の穴、曲線の接触・交差、クリップ、複雑なCSSなどは未対応または安全側に拒否する。
- ベクターのプレビュー書込みを対象別に順序付け、VM API 経由の外部更新と取消・Undo／Redo の競合を世代付きの比較更新で保護した。プロジェクト切替時の古い書込みや実行中の同期も検証した。遅延中の移動後に図形を追加すると正常なUndoを外部競合と誤判定する回帰も修正し、保存順序・長時間待機・対象切替を個別の実画面テストで検証した。VM API を迂回した内部オブジェクトの直接変更は保護対象外で、同名ターゲットの名前解決にも制限が残る。
- 初回 Fit とプロジェクトごとの表示状態分離、パン境界、解像度1の表示倍率換算を追加し、透明余白・読み込み競合・切替時の倍率を実画面で検証した。スクロールバーなど未解決の差が残る。
- 細長い画像がキャンバス上限で空になる際、元画像を空 SVG や透明画像で上書きする問題を修正した。上限を超える画像や読み込み画素を検証できない画像は編集・保存・変換を拒否し、元データを保持する。ブラウザー間の寸法制限は未検証。
- 上記以外の調査項目の多くは未修正または未検証であり、完全互換を意味しない。
- SVG 防御追加後にスプライト復元時の SVG アセットのバイト列が変わる回帰を確認し、空要素のシリアライズを修正した。該当するランタイムテストと SVG 安全性テストの再実行は成功した。エディター全体のブラウザー適合テストも成功していない。テストでソース文字列の想定不一致、OffscreenCanvas 読み出しエラー、Blockly フライアウトの想定不一致、タイムアウト後のブラウザー終了が観測された。独立調査では一部のセレクター不一致は HEAD にも存在し、OffscreenCanvas の読み出しはテストの前提とワーカー描画の不一致と判明した。その後の隔離調査では35件中19件が成功し、12件はセレクターや描画読出し・タッチ入力など、4件は外部 fixture 欠落で失敗した。タッチブラシの開始処理と閉形状プレビューの適合試験を修正し、個別テストは成功した。画面読出しのテストも OffscreenCanvas に対応したが他のセレクター差が残る。後の隔離した全体実行は35件中13件成功・22件失敗で、欠落fixture、Blocklyの不一致、ブラウザー終了後の連鎖を含む。明白に古いセレクターは一部更新したが、全体再検証は未完了。

## 現行独自の機能・差分として残すべき可能性があるもの

SVG 数値編集、整列操作、明示的な保存操作、クリックで定型図形を作る操作、独自の回転中心編集などは現行固有の機能。互換化に際して一律削除せず、既存用途への影響を検討する。

## 詳細な差分の確認項目

以下は領域別の調査から挙がった項目で、動作試験が未実施のものを含む。実装方式の違いが必ずしも利用者から見える不具合になるとは限らない。

1. ブラシのベクター生成方式は太さとズームによる切替、固定距離の補間、既存図形との結合、Z 順維持が異なる。
2. ベクター塗りつぶしは hit test、対応可能な穴への塗り、ホバープレビュー、放射状の中心位置を改善した。複雑な穴や文字など全ケースの一致は未確認。
3. ベクター選択はズーム連動 tolerance、ハンドル優先度、グループの子選択、複合パスの選択単位、選択状態の伝播を確認する必要がある。
4. マーキーは交差・包含の判定、Shift 時のトグル、グループの再帰、reshape の点選択、テキストの除外を確認する必要がある。
5. 選択アイテムの移動は Shift 角度スナップと Alt 複製を追加した。中央スナップ、移動可能範囲、中央ガイド、矢印キーの移動量には差が残る。
6. 選択アイテムのスケールは Alt の中心基準、角ハンドルの通常時の縦横比維持と Shift による解除、複数対象の共有中心、重なり順、テキストサイズの反映に差がある。
7. 複数選択の回転と反転は共有中心で行うよう修正し、回転ドラッグハンドルと Shift 角度スナップも追加した。現行の整列ボタンなどは Scratch 固有操作ではない。
8. パス編集は複数点選択・移動、曲線上への点追加、点削除後のハンドル補正、reshape のマーキーとキーボード操作を確認する必要がある。
9. ビットマップの図形は塗りのみ／輪郭のみの排他、描画後の一時的な選択、変形してからの焼付け、回転図形のラスタライズが異なる。
10. ビットマップの選択はドラッグ範囲内の不透明境界への切詰め、浮動ラスタ、元領域の消去と確定、複製、拡縮・回転、端の扱いを確認する必要がある。
11. コピー・貼付はベクターとビットマップの対象、クリップボードの表現、空選択時、繰り返し貼付時の位置ずらし、貼付後の選択を確認する必要がある。
12. テキストはインライン編集、フォント一覧、複数行と行間、編集中のショートカット抑止、拡縮時のフォントサイズとビットマップ確定が異なる。
13. 色は塗り・輪郭の独立設定、第2色の編集、交換、透明／混合状態、スポイトの拡大鏡とアルファが異なる。
14. ズーム／パンは基準点、増分、ホイール修飾、ビュー境界、チェッカーボードやガイドの表示に差がある。
15. 履歴は上限、保存形式、編集前後のタイミング、空操作、コスチューム変更時の初期化とサウンド編集との分離を確認する必要がある。比較開始時は移動・リサイズ開始時に履歴取得を開始していたが、変更が成立した場合に記録する方式に改めた。Scratch の移動も変更が発生した場合に更新する（[移動](../.tmp/scratch-editor/packages/scratch-paint/src/helper/selection-tools/move-tool.js)、[履歴](../.tmp/scratch-editor/packages/scratch-paint/src/helper/undo.js)）。
16. 入出力は SVG のサニタイズ、描画境界、座標・倍率・回転中心、空画像、PNG の解像度、モード切替と画像埋込みを比較する必要がある。
17. UI はモード別のコントロール、サイズの初期値と上限、グループ化・重なり順の有効条件、狭い幅、翻訳・RTL とフォーカスを比較する必要がある。
18. 画像のブラシ・消しゴムの表示はスタンプの画素形状とアンチエイリアス、整数座標への丸め、カーソル表示、ズームを比較する必要がある。
19. 塗りと輪郭の第2色・グラデーション・2色交換を追加した。選択図形の MIXED 表示と部分的な色変更も追加したが、未解決の色表現は変更せず通知する。参照は [fill-style](../.tmp/scratch-editor/packages/scratch-paint/src/reducers/fill-style.js) と [stroke-style](../.tmp/scratch-editor/packages/scratch-paint/src/reducers/stroke-style.js) を分離している。
20. 透明色の選択、透明ストップの補間色、ビットマップスポイトでの透明画素の扱いを追加した。ベクタースポイトも追加した。放射グラデーションのクリック位置やスポイト表示の詳細には差が残る。
21. 外部 SVG の取り込みは、VM 側の正規表現サニタイズを回避した入力がエディターの HTML プレビューで実行されることを、無害なマーカーを使うブラウザーテストで確認した。エディターの表示・Paper 読込境界に DOMPurify ベースの防御、VM の保存時にパーサーベースの防御を追加した。独立監査で見つかった CSS 属性の外部 URL と image-set による通信も遮断し、ブラウザーテストを追加した。VM 側の独立監査で再現された `image-set` 経由の外部通信も遮断し、保存後のバイト列とブラウザー通信を回帰テストした。同梱 Scratch SVG 785件すべてについて、240×180 にレンダリングした RGBA 画素を実 Chrome で処理前後比較し、VM・エディター・連続処理の各経路で完全一致した。このサイズと素材に限る検証であり、未知のSVG全般を保証するものではない。VM は作業用 `data-paper-data` を削除する（785件中76件）。見本で描画差はなかったが、エディター側でも不正な Paper データを除去し、直接 import、SVGからのビットマップ変換、ベクター貼付の経路にサニタイズを追加した。変換されたグループや既存図形の保持をブラウザーテストで確認した。サンプル検査であり、未知の入力全般の安全性や互換性を網羅的に保証するものではない。参照は [paper-canvas](../.tmp/scratch-editor/packages/scratch-paint/src/containers/paper-canvas.jsx) でサニタイズと分離処理を行う。全経路の安全性が確認できるまで、不明な出所の SVG／プロジェクトを開かないこと。
22. 描画履歴は最大100件・容量制限付きに変更し、コスチューム切替時にクリアする。保存形式や容量上限と、選択状態の復元には差が残る。
